# DECISIONS.md — Lyric Reader

Every judgement call made while Nahom slept. Each entry: what I chose, why,
and how to change it. Nothing here is load-bearing — veto anything.

## Reader look & feel

1. **Muted trail = white at 28% opacity, NOT `--muted-foreground`.**
   The design system's dark `--muted-foreground` (0.72 lightness) renders as
   medium grey — far too loud next to the mockup's ~25–30% white trail.
   Trail blocks use `#fff` at `var(--trail-opacity: 0.28)` with a fade mask.
   → Change: edit `--trail-opacity` in `app/src/index.css`.

2. **Primary indigo (266) never touches reader body text.**
   It's reserved for library UI: buttons, progress bars, the "LYRIC READER"
   eyebrow, focus rings. The reader stays pure black + white only.
   → Change: it's just usage discipline; no token to flip.

3. **Current-sentence auto-shrink tiers.**
   Mockup shows one huge sentence; long sentences must not overflow.
   ≤90 chars → 2.6rem, ≤170 → 2.1rem, ≤280 → 1.7rem, longer → 1.4rem,
   all × the user's font-scale (0.8–1.4, A−/A+ in the overlay).
   → Change: `currentFontSize()` in `app/src/components/Reader.tsx`.

4. **Sentence transition: 300ms ease-out, rise + settle.**
   `translateY(10px) scale(0.985)` → rest, opacity 0.35 → 1.
   Transform/opacity only — no layout work per advance, so no jank.
   Disabled under `prefers-reduced-motion`.
   → Change: `@keyframes sentence-in` in `app/src/index.css`.

5. **One sentence per gesture, guaranteed by construction.**
   Navigation uses functional `setPos(p => step(pages, p, dir))` so rapid
   gestures can't skip. Wheel input is locked for 600ms after each step;
   taps are split into thirds (top = back, bottom = forward, middle = overlay);
   pointer swipes need 48px vertical travel. Keys: arrows/space/page keys.
   → Change: constants at the top of `Reader.tsx`.

6. **Headings render in the serif face when current.**
   Gives chapter titles a "title card" moment; in muted blocks they stay
   small like everything else. (Serif file is Noto Serif Georgian 600,
   self-hosted — see 12.)

7. **Bullet hairlines: nested levels only.**
   Level-0 bullets get indent + no hairline (their "parent" is prose, and a
   line to nowhere looked wrong). Nested bullets (level ≥ 1) get a 1px hairline
   at the parent's indent, white at 22% — the thread-line effect.
   Muted blocks use a `•` marker + indent instead of hairlines.
   → Change: `Reader.tsx` (`bullet-hairline`) and `TrailLine`.

8. **Desktop: content column capped at 56rem, centered.**
   The mockup is a phone; at laptop widths uncapped text ran 900px+ wide.
   Phone keeps the mockup's ~12% side margins (`max(1.5rem, 12%)`).

9. **Overlay: hidden until you tap the middle third, auto-hides after 3.5s.**
   Contains ← Library, title, `Page x of y · z%`, thin primary progress bar,
   and A−/A+ font controls. Nothing else lives on the reader screen.

10. **End of book: clamps.** No "finished" screen in v1 — advancing past the
    last sentence just stays put. (Easy to add later if wanted.)

## Pagination & position

11. **EPUB / TXT / paste: ~14 sentences per page. PDF: one reader page per PDF page.**
    The 14-sentence chunk keeps the muted trail from becoming a wall while
    keeping page turns infrequent. PDF pages are natural boundaries already.
    → Change: `SENTENCES_PER_PAGE` in `app/src/lib/extract.ts`.

12. **Reading position = (page, sentence) in IndexedDB, saved debounced
    (500ms) + flushed on `pagehide`. The last-open book id is remembered in
    localStorage, so reopening the app drops you straight back into reading.**
    → Change: `app/src/lib/db.ts`, `App.tsx`.

## Extraction

13. **EPUB parsed with jszip + a hand-rolled OPF/spine walker, not epubjs.**
    Smaller bundle, fully deterministic, no extra dependency. Handles
    h1–h6, p/div/blockquote, nested ul/ol with depth.
14. **PDF text rebuilt by grouping glyphs into lines (y-tolerance 2.5px).**
    Good for single-column prose; two-column layouts may read across columns —
    documented as a known limit.
15. **Sentence splitter = `Intl.Segmenter` + abbreviation merge rules**
    (Dr., e.g., Fig., decimals, initials, ellipses). Rules live in
    `app/src/lib/segment.ts` and are unit-tested.
16. **DOCX not included in v1.** Spec listed it as "if time"; PDF/EPUB/TXT +
    paste-text cover the MVP. Say the word and I'll add mammoth.js.

## Fonts, icons, PWA plumbing

17. **Fonts self-hosted in `/fonts`, precached by the service worker:**
    Geist Regular + SemiBold and Geist Mono Regular from the `geist` npm
    package; Noto Serif Georgian 600 (latin + latin-ext subsets) fetched from
    Google Fonts at build time. If a file ever goes missing the stacks fall
    back to system fonts — the app still works.
18. **Icons generated by a zero-dependency Node script**
    (`app/scripts/make-icons.mjs`): "lyrics bars" motif — five primary-indigo
    bars on pure black, 192/512 + maskable-512 with safe-zone padding.
19. **Service worker via `vite-plugin-pwa` (generateSW).**
    Precaches everything including the pdf.js worker (cache cap raised to
    12MB); `navigateFallback: index.html` so reloads work offline.
    Chose the plugin over a hand-rolled SW for reliability.
20. **App is dark-only** (`<html class="dark">` forced) — the whole product is
    the black reader; a light theme would fight the mockup.

## Content

21. **Sample book "Sample — The Midnight Staircase"** (60 sentences, 5 pages)
    is original prose written for testing: paragraphs, headings, nested
    bullets. Seeded once on first run (guarded against double-seeding).

## Post-launch: self-generating assets (Oct 18, ~23:57 EAT)

- **Context:** The GitHub connector push is UTF-8-text-only and this environment's browser file-upload is blocked, so the font (.woff2) and icon (.png) binaries could not be committed to the repo — which Vercel needs in order to build from GitHub.
- **Decision:** The build now generates its own binaries. `app/scripts/copy-fonts.mjs` copies the five fonts from the `geist` and `@fontsource/noto-serif-georgian` npm packages into `public/fonts`, and the existing `scripts/make-icons.mjs` draws the three PNG icons — both wired as `prebuild` in `app/package.json`, so local builds and Vercel builds produce identical output with zero binaries in git. The generated files are git-ignored.
- **Verified:** deleted all local font/icon binaries, `npm run build` regenerated everything, dist complete, reader e2e suite still 7/7.
- **Veto/change:** to pin exact font files instead, commit the binaries with a local git client and remove the `prebuild` script.
